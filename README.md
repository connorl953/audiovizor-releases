# AUDIOVIZOR — Releases

Desktop app releases for [AUDIOVIZOR](https://audiovizor.com), a real-time audio visualizer with 15+ reactive presets, beat detection, and video export.

## Download

Download the latest installer from the [Releases](https://github.com/connorl953/audiovizor-releases/releases) page.

**Windows:** Download the `.exe` installer and run it. The app will auto-update when new versions are available.
